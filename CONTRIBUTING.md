# Contributing Guidelines

Thank you for your interest in contributing to the **Resume Screening & Categorization System**!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Make Your Changes & Test**
   - Ensure new code follows PEP 8 standards.
   - Run unit tests:
     ```bash
     pytest -v
     ```
4. **Commit Your Changes**
   ```bash
   git commit -m 'feat: add amazing new capability'
   ```
5. **Push to Your Branch**
   ```bash
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request**

## Code Style & Testing
- Use clear docstrings and type hints for public functions.
- Run `flake8` to check formatting before submitting PRs.
- Write tests for any new features in `tests/`.
